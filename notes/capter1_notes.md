# 第一章

## 人工智能的定义

在人工智能领域，智能体被定义为任何能够通过传感器（Sensors）感知其所处环境（Environment），并自主地通过执行器（Actuators）采取行动（Action）以达成特定目标的实体。

### <strong>
    个人理解无论是传感器、还是感知环境、还是执行器、采取行动理论都是通过API形式的调用
</strong>


真正赋予智能体"智能"的，是其自主性（Autonomy）。智能体并非只是被动响应外部刺激或严格执行预设指令的程序，它能够基于其感知和内部状态进行独立决策，以达成其设计目标。这种从感知到行动的闭环，构成构成了所有智能体行为的基础。

### <strong>
    自主性核心是通过大预言模型
    输入 A → 理解 → 推理 → 选择 → 行动 → 反馈 → 调整

    传统
    输入 A → 固定规则 → 输出 B
    多出来的中间环节，就是"自主性"的来源。


    所以"自主性"的本质是：
    我不是执行"你让我做什么我就做什么"的指令映射，而是：
    理解你的意图
    根据当前环境（文件、记忆、工具能力）
    自己规划"怎么做"
    在执行过程中根据反馈调整
    这个"现场规划+动态调整"的能力，就是智能体和传统脚本的本质区别。
</strong>
